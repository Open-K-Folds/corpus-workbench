# Migration milestones

The complete [approved plan, public edition](docs/APPROVED-PLAN.md) contains 34 backlog items and 36 source references. This preview completes a first usable slice, not the whole migration.

- [x] Complete-package lossless import, immutable source objects and revision-safe native SQLite authority.
- [x] Supported lexical XML corrections, custom language values, discontinuous spans/relations and Unicode/reference/time validation.
- [x] Exact review, diff, named history, per-edit undo/redo, restore and approval invalidation on change.
- [x] Usable TypeScript audio/edit/history/review/export flows, tested in a real isolated browser.
- [x] Complete additive exports and reopen/receipt/history/object validation; verified backup/restore and process crash recovery.
- [x] Independent review and repair of six demonstrated first-slice defects; additional authored graph topology rejection verified.
- [x] Local native Semantica generations bound to approved exact evidence and effective recipe; stale/rejected evidence excluded from current queries.
- [x] Reference-safe edits of existing spans/relations, explicit Unicode anchor repair, scoped diffs and competing-draft protection; [evidence and limits](docs/ANNOTATION-MILESTONE.md).
- [x] Exact-revision artifact/lexical reference inventory, usable inspection and blocked structural preflight, qualified V2 compiler identities with immutable V1 history; [evidence and remaining gates](docs/REFERENCE-INVENTORY-MILESTONE.md).
- [x] Whole-package closed-dialect split/merge proof, atomic successor lineage, Unicode/span/reference repair, usable draft-safe form and repeated export/reimport; [evidence and bounded scope](docs/RETOKENIZATION-MILESTONE.md).
- [x] Revisioned finite TEITOK reader settings/definition, native browser reopen without manual project fixes; [evidence and limits](docs/TEITOK-READER-MILESTONE.md).
- [x] Detailed authoring experience: corpus/source navigation, search/filter/status, readable review/diff/history, recoverable drafts, keyboard access and typed extensibility; [behavior and limits](docs/AUTHORING-EXPERIENCE.md).
- [x] Local container workflow: pinned multi-stage builds, exact-source contexts, Compose development/test, non-root persistent storage, readiness, backup/restore, documented safe upgrade/rollback and x86-64/ARM64 CI configuration; [tested scope and gates](docs/CONTAINER-MILESTONE.md).
- [x] Bounded dev.7 dependency/license, offline image assessment and compatible cross-version upgrade/rollback qualification; [evidence and remaining gates](docs/RELEASE-QUALIFICATION.md).
- [x] One dev.8 Trixie runtime candidate: exact inventory, unchanged contracts under actual loader, browser and upgrade/rollback qualification, comparative scan and independent review; [tested evidence and remaining decisions](docs/TRIXIE-RUNTIME-MILESTONE.md).
- [ ] Hosted native ARM64 container CI, native Pi/resource qualification and approved registry publication.
- [ ] Full TEITOK/CWB/CQP parity and arbitrary-schema/structural editing; external exported-package lineage reconciliation.
- [ ] Native durable job/outbox/worker fencing, shared assertions, ontology/model recipes and permanent rights-withdrawal lifecycle.
- [ ] Portable optional compiler dependency lock, human linguistic review, native Pi validation and production backup/roles/operations.

The current source baseline is 134 Rust tests (36 core contracts, 19 annotation edits, six export integrity, ten generations, three earlier abrupt-process recovery, 15 reference inventory, 22 structural contracts/recovery, three review regressions, ten reader-profile contracts, four migration recovery, two readiness, three closed-backup contracts and one compiled SQLite version contract), eighteen host browser flows and one additional container browser/persistence journey. The immutable preview retains its 54-test/three-flow baseline. A separate optional native Semantica 0.6.8 smoke exercised eight nodes and thirteen authored edges across approved R1/R2, plus three annotation generations (13/13/12 edges), and qualified repeated-ID evidence (seven nodes/eight edges), native reopen, idempotent reuse, stale/forged rejection, backup restore and review invalidation. Three additional structural native generations (7/13, 8/16, 7/13 nodes/edges) verify exact reviewed split/merge without changing retired graph objects or inventing timing. That optional runtime is locally supplied and is not installed or claimed verified by the public CI.

Every public release records its own exact source commit, actual commands/results, target platforms, dependency audit and checksums. Historical local validation is recorded as provenance; it is not a substitute for the public exact-commit checks. Raspberry Pi hardware and physical power-loss testing have not run.
