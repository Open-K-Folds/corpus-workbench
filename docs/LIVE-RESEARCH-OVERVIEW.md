# Research overview

Open **Research overview** from a loaded workbench. It is an optional, read-only
instrument view; **Return to transcript** restores focus and the existing editor,
including unsaved drafts. It does not import, save, approve, compile or export.

The curved evidence view shows files belonging to the exact saved snapshot.
The active document source and its unambiguous media reference appear first.
Other files are package members, not inferred semantic links or a claim that a
raw artifact generated a particular document. The full source hashes and roles
of the first 16 files are available in the file disclosure; omitted totals remain
visible. The normal Sources inspector retains the complete inventory.

The recording view reuses the existing bounded local audio analysis. The upper
trace aggregates peak amplitude without dropping source peak bins. Eight lower
traces summarize sampled frequency-band display intensity, ordered low to high.
They describe the recording, not words, speakers, language or confidence. No
additional decode, model, media upload or second audio source is introduced.
Existing analysis limits remain 32 MiB and ten minutes; playback can still be
available when the static analysis is unavailable. Missing data is labelled.

Bright path highlights follow actual recording playback only. **Pause motion**
freezes the trace playhead and path highlights while the recording continues.
Reduced motion disables those animations and automatic playhead movement.
Explicit seeking remains available. Hidden/closed overviews stop animation;
closed overviews stop polling. Automatic trace redraws are capped at ten frames
per second; the transport continues to show the actual recording position.

The selection shows up to 32 saved token readings and their supplied timing.
Segment/chunk bounds remain distinct from word bounds. Unsaved drafts are
excluded. Counts, approval and validation come from the saved editor basis.
The overview never changes the current review gate.

On desktop, the overview reads local Semantica state on open, on refresh and at
most once every three seconds while visible, with one request in flight. Late
responses cannot relabel a different revision or project. A graph is current only
when its revision and hash match the approved basis with no blocking issues.
Native reopening, legacy mapping, failed/interrupted attempts, busy states and
verified portable export are identified separately. Browser mode explicitly
reports that the desktop runtime is unavailable and invents no counts.

The six-entry session list records locally observed changes, not historical
audit events. Exact saved history and review provenance remain in their normal
inspectors. All labels and controls remain available without animation, hover
or colour. The dialog supports keyboard focus containment and Escape.

The visual language uses stable monochrome linework and restrained activity.
Reference media is kept outside the repository. Qualification uses generated
tones, authored synthetic text and isolated profiles only.
